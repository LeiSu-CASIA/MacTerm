These libraries are statically linked into MacTermRDP. The local FreeRDP
clipboard transport modification is documented below. Their fixed official source URLs and SHA-256 checksums are
listed in sources.json. Project-local build scripts record all build options.
The application does not require a system FreeRDP, OpenSSL, CMake, or Python
installation at runtime. macOS system frameworks and zlib are used separately.

Local FreeRDP modification: channels/client/addin.c adds a cliprdr-only bound of 2,162,688 bytes per fragmented message and at most 16 queued messages before allocation/queueing. The reproducible patch is tools/patch-rdp-clipboard.py in the MacTerm source. Only the cliprdr client/server channel is compiled into this build; file streaming capabilities are not advertised.
