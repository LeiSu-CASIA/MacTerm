# VNC 远程桌面

0.3.27 首版、0.3.28 增加双向文本剪贴板，在 MacTerm 标签页内运行 noVNC 1.7.0，使用 macOS Network.framework 的独立 TCP 连接。无需在远端安装 WebSocket 代理。构建仍使用 Command Line Tools，不需要完整 Xcode；运行时不需要 Node。

## 使用

1. 顶部「新建会话 → VNC 远程桌面…」；也可使用「会话」菜单。
2. 输入主机、端口（默认 5900）、可选用户名、分组与连接超时。端口填写实际 TCP 端口，例如 5901，而非桌面编号 `:1`。
3. 双击会话连接。服务器需要认证时弹出本机密码输入框。密码仅用于当前连接，不保存到会话文件或 URL；此版未提供 VNC 钥匙串记忆。
4. 标签页内可切换「适应窗口」与原始尺寸滚动，向当前桌面发送 Ctrl+Alt+Delete。只读会话禁用键鼠与此组合键。
5. 点击标签内剪贴板图标打开双向文本预览。远程更新只进入本标签缓存；「刷新远程预览」固定显示一份快照，「复制预览到本机」才将这份快照写入本机剪贴板。也可使用原生文本选择 / 复制操作。
6. 本机文本可主动读取到下方预览，或直接输入 / 粘贴；核对后按「发送预览到远程」。传送不自动在远程应用粘贴或执行。空文本可以清空远程剪贴板；只读模式禁用全部剪贴板功能。
7. 关闭标签会取消此标签的连接；使用「终端 → 重新连接」或 ⌘R 新建连接。

快速连接接受 `vnc://hostname:5900` 或 `vnc://[IPv6]:5900`。地址不接受用户名、密码、路径或查询参数。会话支持已有分组、收藏、最近连接、复制、导入与导出操作。

传统 VNC 不加密画面，请在可信网络中使用，或先通过 SSH 隧道连接本机转发端口。当前没有自动 VNC 跳板机 / SSH 封装，也没有自动读取、发送或写入 macOS 剪贴板。UTF-8 扩展服务器发送时先收到通知，服务器请求后才传文本；界面会区分等待请求与已提交，二者都不等于服务器已确认送达。传统剪贴板只接受 Latin-1，发送中文或表情会明确失败，此次不会发送替代问号。VNC 不提供 SFTP；文件操作请使用 SSH 标签。

## 实现与边界

- noVNC 的公开 RFB 接口接受原始通道，WKWebView 与本机 TCP 之间以有界二进制桥接。每次接收最多 64 KB，渲染器处理后才读取下一块；原生待发送缓冲最多 8 MB，单条消息最多 4 MB。超过限制报错并断开。
- TCP 就绪显示协商中，只有 RFB 完成初始化后显示已连接。取消、认证失败、协议失败、服务器断开和超时分别结束当前连接，不能以 TCP 连通代替桌面连接成功。
- 页面仅载入包内资源，禁止外部网页导航与页面网络连接；WebKit 使用临时数据存储。服务器名称及错误文字按文本显示。
- 用户名 / 密码通过原生安全输入框输入并送到本标签页内存中的客户端。未接入服务器指纹确认的认证方式会明确失败，不自动信任。传统 VNC 密码认证通常只使用前 8 字节。
- 画面限制为每边最多 16,384 像素且总计最多 32,000,000 像素；限制在分配帧缓冲前检查。超限会话断开。
- noVNC 内核修改包括 Display.resize 尺寸检查，以及剪贴板扩展包长度校验、线缆数据 / 解压大小限制、避免 Latin-1 静默替换、提交状态返回和断开时释放待传文本；构建工具固定目标源码并校验补丁位置。完整对应源码（含修改说明、作者和第三方许可证）打包为 `Contents/Resources/noVNC-source.tar.gz`，另附 `noVNC-LICENSE.txt`。构建步骤在 `tools/build-vnc.mjs`。

## 验证

`Tests/vnc_server.py` 是独立的 loopback RFB 3.8 测试服务器，不使用 noVNC 实现。`build/vnc-test --renderer` 在实际 WKWebView 中验证红蓝画面像素、DES challenge/response 密码认证、实际键鼠消息、只读阻止输入、分辨率变化后画面像素、超限帧缓冲、不支持认证、超时和关闭后隔离。

`Tests/VNCClipboardTest.swift` 的 `--renderer` 用例配合同一独立服务器，验证传统 Latin-1、UTF-8 / 表情 / 跨行文本、原始压缩流、服务器不拉取、1 MiB 换行转换、空文本清空、只有主动操作才访问专用测试剪贴板、快照不被后续远程更新替换、过量 / 负数解压长度、畸形扩展包、只读和关闭清理。所有测试使用独立命名剪贴板，不读写用户的系统剪贴板。`test.sh` 已加入这些用例。

文本上限为 1 MiB（UTF-8），不接受 NUL。远程超限文本会丢弃缓存与旧预览；压缩协议在分配前限制为 4 MiB 线缆数据和总计 2 MiB + 终结 NUL 的解压数据，以容纳 1 MiB LF 文本在协议中的 CRLF 展开。断开 / 重连不保留文本，关闭预览窗口清空发送草稿，所有文本均不写入会话文件。

自动化结果不等于跨服务器完整兼容。真实 macOS / Linux / Windows VNC 服务、各类认证与压缩编码、修饰键 / 中文输入法、全屏与 Retina 画面仍需继续验收。RDP 已有独立内嵌首版，范围与验收边界见 [RDP 接入说明](RDP接入.md)。

接口依据：[noVNC API](https://novnc.com/noVNC/docs/API.html)，打包源码来自固定的 npm `@novnc/novnc@1.7.0`。

手动提交的本机文本保持为当前连接的待提供内容，直到再次手动提交或断开；迟到的远程剪贴板更新只更新远程预览，不撤销较新的本机提交。没有自动读取或改写系统剪贴板。
