# RDP 远程桌面

0.3.29 首版通过 FreeRDP 3.33.0 运行真实 RDP 客户端，AppKit 视图直接显示软件帧缓冲。每个标签拥有独立的内核进程和输入通道。内核运行时只依赖随应用打包的程序与 macOS 系统库，不启动外部查看器、不需要 Node / Python 或完整 Xcode。

## 使用

1. 「新建会话 → RDP 远程桌面…」输入主机和端口（默认 3389）。端口是实际 TCP 端口。可保存用户名、域 / 计算机名、分组、桌面尺寸、超时与只读设置。
2. 默认「要求 NLA 网络级身份验证」。取消要求后允许 NLA 或 TLS 登录，仍不允许旧式 RDP 安全模式。状态栏显示实际协商出的 NLA 或 TLS。
3. 双击会话，在本机安全输入框输入密码。域可单独填写，也支持 `DOMAIN\username`。密码不保存；重新连接时重新输入。
4. 系统证书验证通过后继续登录。对不受信任、名称不匹配或过期的证书，默认取消；只有核对服务器 SHA-256 指纹后才选择「仅本次继续」。这不会修改系统根证书或保存永久例外。
5. 标签内可切换适应窗口 / 原始像素尺寸滚动。「发送按键」向此标签发送 Ctrl+Alt+Delete、Windows 键或 Alt+Tab。只读会话禁用输入和这些操作。
6. ⌘C、⌘V、⌘A 对应远端 Ctrl+C、Ctrl+V、Ctrl+A，作用于远端自己的剪贴板。点击工具栏「剪贴板」可明确传输本机与远程的文本，快捷键本身不读取本机剪贴板。⌘W、⌘R、⌘Q 保留关闭标签、重新连接和退出应用。
7. 关闭标签会释放本标签的按键并断开连接，保留远程服务器上的会话，不执行远程注销。重新连接不会沿用上次密码、临时证书确认或待发输入。

快速连接为 `rdp://hostname:3389` 或 `rdp://[IPv6]:3389`。地址不接受用户名、密码、路径或查询参数。文件传输仍使用 SSH / SFTP 或 FTP 标签；RDP 首版不重定向本机磁盘。

## 当前范围

- 支持直接 RDP 主机的 NLA（NTLM）与 TLS、固定桌面尺寸、软件画面、键鼠、Unicode 提交、组合键、只读和关闭 / 重连。
- 本地输入法有独立组合区，组合过程只显示在本机，提交后才传文字。跨输入法的实际候选窗口 / 修饰键行为仍需人工验收。单次文本最多 4096 UTF-16 单元，无 NUL。
- 已实现最大 1 MiB 的 Unicode 文本剪贴板（明确读取 / 复制 / 载入 / 发送，只读仅接收）。不包含剪贴板文件 / 图片、音频 / 麦克风、磁盘 / 打印机 / 智能卡、多显示器、网关 / RDS 服务器重定向、AAD 或 Kerberos 登录。不能把首版测试扩大为这些功能已支持。
- 没有把主窗口变化自动变成服务器分辨率变更；可在会话设置中选桌面尺寸。能够接收服务端的分辨率变化。
- 使用 macOS 本地证书策略，检查证书链、主机名和有效期；不联网下载缺失的中间证书或执行在线撤销查询。缺失链等情况会失败并进入明确的指纹确认流程。
- 当前二进制按这台 Apple Silicon Mac 构建。Intel、旧版 macOS 和实际 Windows 服务端矩阵仍待验证。

## 实现与资源限制

- FreeRDP / WinPR 3.33.0、OpenSSL 3.5.9 LTS、cJSON 1.7.19 固定源版本和 SHA-256，取自各官方仓库。构建源与摘要在 `build/rdp-deps/sources.json`。不复用其他软件环境的加密动态库。
- `MacTermRDP` 通过私有 stdin/stdout 帧协议通信，不接受命令行密码；普通输入消息最多 64 KiB；协商剪贴板后允许最多 4 MiB 的剪贴板帧。主进程普通输入积压仍限 1 MiB，总积压限 8 MiB；内核命令队列最多 128 项 / 8 MiB。连续鼠标移动可合并，按键和按钮不丢弃，超量报错断开。
- 原始画面为 BGRX，单块最大 4 MiB，桌面每边不超过 8192、总计不超过 1600 万像素，分配前检查。主进程接收时再检查尺寸 / 坐标 / 长度，按块复制并合并重绘。
- 输出读取在消费完当前块后才继续，避免主线程忙碌时积压画面。错误、超时、取消、内核退出和证书任务都有标签级状态；过期证书回复不会作用于新连接。
- 登录配置和密码不写入磁盘。所属临时目录仅供内核配置使用，连接关闭后清理；进程崩溃不会让旧输入转到新标签。原始 RDP 输出不进入终端日志 / 宏 / 广播。
- 第三方许可证、来源版本与哈希随应用保存在 `Contents/Resources/RDP-Licenses/`。FreeRDP 的 cliprdr 分片 / 队列接收有文末所述局部边界补丁；OpenSSL 源码未修改，补丁随许可证资料保存。

## 验证证据

`Tests/rdp_server.c` 是本机独立进程的 FreeRDP 服务端，只绘制指定色块，不读取屏幕。`Tests/rdp_fixture.py` 生成临时根证书、服务器证书和测试账号哈希。`Tests/rdp_engine.py` 通过实际 TCP / TLS / CredSSP / RDP 流验证内核，`Tests/RDPTest.swift --renderer` 验证原生视图、系统证书策略、输入与清理。客户端和服务端共用同一版 FreeRDP，所以尚需补做 Windows 10 / 11 / Server 的互通验收。

覆盖错误密码、证书拒绝、强制 NLA、只读、认证前输入隔离、Unicode / 表情、键盘 / 鼠标、颜色 / 行方向、分辨率改变后的新画面、巨大尺寸和非法 IPC、断开后资源及过期回复。所有账号 / 证书 / 端点都是测试专用；没有连接用户服务器、录制桌面或读取用户系统剪贴板。

完整回归入口：`./test.sh`。测试共用一次编译好的业务模块，各套用例仍在独立进程运行；测试动态库不会被应用加载。

依据：[FreeRDP 3.33.0](https://github.com/FreeRDP/FreeRDP/releases/tag/3.33.0)、[官方示例客户端](https://github.com/FreeRDP/FreeRDP/tree/3.33.0/client/Sample)、[OpenSSL 下载与生命周期](https://www.openssl-library.org/source/)。


## 0.3.40 文本剪贴板

先在远程应用复制文本，再打开 RDP 标签内的「剪贴板」，点击「读取远程文本」取得预览；点击「复制预览到本机」才改写本机剪贴板。另一方向可点击「读取本机剪贴板」载入草稿，也可直接输入并编辑，再点击「发送预览到远程」。服务器确认格式后仍需在远程应用粘贴，不会发送 Ctrl+V 或自动执行文本。发送采用 Windows CRLF 换行，换行转换后的 UTF-8 计量最多 1 MiB。空文本可以显式提供 / 复制，不支持 NUL、文件、图片或传统非 Unicode 文本格式。

本机剪贴板不会在连接、开面板或远程内容变化时自动读取或改写。预览仅保留当前成功读取的远程版本，远程复制新内容后旧预览失效。请求与确认超时后该方向停止重试，需重连，以免无编号的迟到协议响应被用于另一次请求；桌面操作不因普通剪贴板错误停止。关闭会话清空面板和待处理状态。服务器未启用剪贴板通道、远程尚未复制 Unicode 文本或策略禁止时，面板明确显示不可用。

通道仅协商文本所需的长格式名能力，不宣告文件流、文件锁定或巨型文件能力。实现参考 [Microsoft MS-RDPECLIP](https://learn.microsoft.com/en-us/openspecs/windows_protocols/ms-rdpeclip/) 和 [通用能力集说明](https://learn.microsoft.com/en-us/openspecs/windows_protocols/ms-rdpeclip/7718c8c9-798d-4788-bb75-64afdc913869)，并使用打包的 FreeRDP cliprdr 静态通道。源码的局部补丁在分片分配和队列投递前限制 cliprdr 消息大小与队列数，补丁随应用许可证资料提供。
